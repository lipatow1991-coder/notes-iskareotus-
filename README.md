# NOTES ISKAREOTUS 🖤

**Независимый музыкальный проект — симфонический готик-метал, тёмное фэнтези и музыкальные истории.**

NOTES ISKAREOTUS создаёт музыку с использованием **Suno Premier** и творческой работы автора: постановка музыкальной задачи, работа с сюжетом, музыкальными промптами и выбор вариантов звучания.
